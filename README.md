# Suitcase E-shop

A responsive, multi-page static e-commerce frontend. Product data is loaded from local JSON.

## Prerequisites

- [Node.js](https://nodejs.org/) with npm
- A modern web browser

## What the commands do

- `npm install` installs the project dependencies listed in `package.json` and `package-lock.json`, including Sass, TypeScript, and the development server.
- `npm run dev` compiles the SCSS and TypeScript, then starts file watchers and the local development server on port `3000`. Sass is compiled automatically; no separate compilation command is needed.

## Setup and run

From the project root, run:

```bash
npm install
npm run dev
